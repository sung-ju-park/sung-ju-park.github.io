02 Problem

판매자가 입력한 정보만으로 시세를 맞힐 수 있을까

중고차 매물 데이터는 판매자가 직접 입력한 값이라 가격 미기재(0달러), 자리표시 주행거리, 제각각인 모델명, 같은 차의 반복 게시가 섞여 있습니다. 이 데이터로 '모델·연식별 시세표'보다 정확한 시세를 예측하고, 한 숫자가 아니라 믿을 수 있는 시세 범위와 그 근거까지 보여주는 것이 목표였습니다.

03 분석 내용

What was done

  • 정제 규칙 6단계와 모델명 정규화('F150 XLT', 'super duty f-250' → 기본 모델명, 트럭 적재 등급 추출)
  • VIN 기반 중복 판정으로 반복 게시된 매물 187,872건 정리, 둥근 주행거리는 가격까지 같아야 같은 차로 판정
  • 시세표 기준선, Ridge, Random Forest(정수 코드·타깃 인코딩), XGBoost(기본·Optuna 튜닝) 비교, 모든 실행 MLflow 기록과 모델 레지스트리 등록
  • SHAP 값으로 가격 결정 요인 해석, 차종·가격대·연식별 오차 분석, 트럭 전용 모델 필요성 검증
  • 분위수 회귀와 CQR 보정으로 80% 시세 구간 제공, FastAPI 서빙과 pytest 테스트
04 Technical Challenge

점수가 너무 잘 나오는 평가 방식

원본 매물의 44%는 딜러가 같은 차를 여러 지역에 반복 게시한 것이었습니다(한 대가 최대 261번). 이를 그대로 두고 매물 단위로 무작위로 나누면 평가 매물의 56%가 학습 데이터에 이미 있는 차가 됩니다. 모델이 시세를 배운 게 아니라 그 차의 가격을 외워서 맞히는 셈입니다.

중복 포함 무작위 분할
→
평가 매물 56%가 이미 본 차
→
±20% 적중 80.4%로 부풀려짐
05 Solution

VIN으로 같은 차를 묶어 최신 게시물 하나만 남기고, 차 단위로 평가 데이터를 먼저 떼어 두었습니다. 평가 데이터는 모델 선택이 끝난 뒤 한 번만 썼습니다. 같은 모델 설정으로 비교하면 정직한 평가의 ±20% 적중률은 69.5%입니다. 이후 모든 수치는 이 방식으로 쟀습니다.

06 Result

XGBoost가 시세표 방식 대비 오차율 중앙값을 18.5% → 12.3%, 평균 절대 오차를 $3,712 → $2,434로 줄였고, 실제 가격 ±20% 안에 든 비율은 70.1%입니다.

트럭·픽업은 시세표 방식의 오차가 20.4%로 컸지만, 모델이 12.5%로 줄여 차종 가운데 가장 큰 폭(39%)으로 개선했습니다. 트럭만으로 학습한 모델과 전체 모델의 차이는 거의 없어(12.47% 대 12.51%) 하나의 모델로 운영하기로 했습니다.

분위수 회귀만으로 만든 80% 구간은 실제로 75.4%만 담았습니다. CQR 보정으로 80.3%로 맞췄고, 차종별로도 80% 근처를 유지했습니다.
