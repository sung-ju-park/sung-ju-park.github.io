02 Problem

채용 공고마다 마감일을 일일이 확인해야 하는 번거로움

취업을 준비하다 보면 여러 사이트에 흩어진 채용 공고와 자격증 시험 일정을 각각 따로 확인하고 기억해야 합니다. 이 불편함에서 출발해, 공고 URL 하나만 입력하면 정보와 마감일이 캘린더에 자동으로 반영되는 앱을 팀으로 기획·개발했습니다.

04 Technical Challenge

채용 사이트마다 페이지 구조가 달라, 하나의 크롤러로 일정을 안정적으로 뽑아내기 어려움

구직 사이트마다 공고 페이지의 HTML 구조와 마감일 표기 방식이 제각각이라, 단순히 텍스트를 긁어오는 방식으로는 안정적으로 정보를 추출하기 어려웠습니다. URL을 입력받아 필요한 정보(제목, 기업정보, 마감일)만 정확히 골라내는 크롤링 로직 설계가 핵심 과제였습니다.

05 Solution

FastAPI로 별도의 크롤링 서버를 구축해, 프론트엔드(React Native)와 크롤링 로직을 분리했습니다. 공고 URL을 받으면 서버가 페이지를 파싱해 제목·기업정보·마감일을 추출하고, 사용자가 이를 캘린더 일정과 체크리스트로 바로 저장할 수 있도록 DB와 API를 설계했습니다.

06 Result

채용 공고 URL만 넣으면 마감일이 자동으로 캘린더에 반영되는 구조를 구현했습니다. 팀 프로젝트로 완성해 실제로 Google Play Store에 배포까지 진행했습니다.
